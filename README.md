## 📊 1. Financial Data Analysis Dashboard

**Tech Stack:** `Power BI` `Excel` `DAX`

- Built an interactive Power BI dashboard tracking **12+ KPIs**.
- Reduced manual reporting effort by approximately **40%**.
- Replaced **5 static Excel spreadsheets**.
- Performed variance analysis.
- Identified **3 key cost-driver segments**.
- Delivered data-driven recommendations.
- Recommendations improved profit margins by **15%**.

---

## 🎯 2. Customer Churn Prediction

**Tech Stack:** `Python` `Scikit-learn` `Pandas` `Machine Learning`

### 🔹 Highlights

- Developed a **Random Forest classification model**.
- Used **7,000+ customer records**.
- Achieved **85% accuracy**.
- Achieved **0.82 AUC-ROC**.
- Outperformed the baseline model by **8% in F1-score**.
- Identified the **top 3 churn drivers** through feature importance analysis:
  - Contract type
  - Tenure
  - Monthly charges
- Developed insights to support customer retention strategies.
- Retention strategies were estimated to reduce churn by **18%**.

---

## 🛒 3. Retail Sales Performance Dashboard

**Tech Stack:** `Python` `Power BI` `Pandas`

### 🔹 Highlights

- Analyzed **50,000+ retail transactions**.
- Applied **Pareto analysis**.
- Discovered that **20% of SKUs generated 78% of total revenue**.
- Insights directly guided inventory strategy.
- Automated the end-to-end data pipeline.
- Automated:
  - CSV extraction
  - Data cleaning
  - Visualization
- Reduced data preparation time from **3 hours to under 20 minutes**.
